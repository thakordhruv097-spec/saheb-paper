# Festival Theme System - Saheb Paper Login Page

## Overview
Automatic festival-themed login page that changes based on Indian calendar dates. No admin intervention required - the system automatically detects the current date and applies the appropriate festival theme.

## 💻 Technical Implementation

### Auto-Detection Logic:
```typescript
// Automatically detects current date and applies theme
const festivalTheme = getFestivalTheme(new Date());

// Returns:
// - Theme object if festival is active
// - null if no festival (default Saheb Paper theme)
```

### Manual Theme Testing:
```typescript
// Test specific festival theme
const diwaliTheme = getFestivalTheme(new Date('2026-10-25'));
const holiTheme = getFestivalTheme(new Date('2027-03-15'));
```

### Getting AI Prompt Programmatically:
```typescript
import { getAntigravityPrompt } from './festivalThemes';

// Get prompt for current active festival
const currentPrompt = getAntigravityPrompt();

// Get prompt for specific festival
const diwaliPrompt = getAntigravityPrompt('Diwali');
const holiPrompt = getAntigravityPrompt('Holi');
```

## 🎨 Design Guidelines

### Image Specifications:
- **Resolution:** Minimum 1920x1080 (8K preferred)
- **Format:** WebP (for performance)
- **File Size:** Under 500KB (optimized)
- **Composition:** Clean, UI-friendly, no text overlay
- **Style:** Modern, premium, professional photography aesthetic
- **Focus:** Industrial paper mill merged with festival aesthetics

### Color Accuracy:
- Use exact hex codes provided in prompts
- Maintain brand consistency with Saheb Paper purple (#5E3BE8) as accent
- Ensure sufficient contrast for text readability

### File Naming Convention:
```
login_bg_diwali.webp
login_bg_holi.webp
login_bg_navratri.webp
login_bg_independence.webp
(etc.)
```

## Deployment Notes

### Zero Configuration Required:
- System automatically detects date on page load
- Applies appropriate festival theme
- Falls back to default Saheb Paper theme outside festival dates

### Admin Benefits:
- No manual updates needed
- No configuration panel required
- Works automatically year after year
- Calendar-based, self-sustaining

### Performance:
- Lazy-loads festival backgrounds
- Cached in browser
- Optimized WebP images
- Smooth theme transitions
