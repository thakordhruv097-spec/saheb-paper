## 🎯 Key Features

### 📊 Complete Production Management
- **Real-time Dashboard** with live KPIs and production metrics
- **Parent Roll Logging** with shift-based production tracking
- **Rewinder Operations** for reel conversion and slitting
- **QR Traceability** from raw material to finished goods

### 🏭 Manufacturing Operations
- **Pulp Mill Management** with chemical recipe formulations
- **Raw Material Stock** tracking and inventory management
- **Quality Control Lab** with automated test certificate generation
- **Machine Production** monitoring and telemetry

### 🚚 Supply Chain & Dispatch
- **Customer Order Booking** and tracking
- **Finished Goods Inventory** categorization
- **Delivery Challan** generation with QR codes
- **Gate Pass System** with vehicle weighment

### ⚡ Utilities Management
- **Boiler Operations** monitoring (steam, pressure, fuel consumption)
- **Effluent Treatment Plant (ETP)** compliance logging
- **Electricity & Power Grid** usage tracking and analysis

### 🔐 Advanced Security & Access Control
- **6 Role-Based Access Levels**: Admin, Plant Manager, Pulper Operator, Shop/Store, Dispatcher, Viewer
- **PIN-based Authentication** with secure role switching
- **Worker Login Simulation** for admin testing
- **Audit Logs** for all critical operations

### 🌍 Multilingual Support
- **English** (Default)
- **Hindi** (हिंदी)
- **Gujarati** (ગુજરાતી)

### 📱 Mobile-First Design
- **Offline-First Architecture** with local data persistence
- **Touch-Optimized Interface** for shop floor use
- **Native Hardware Integration**:
  - Barcode/QR Scanner (Hardware accelerated)
  - Thermal Printer Support (ESC/POS, TSC, Zebra)
  - PDF Generation & Sharing
  - Native File Downloads
  - Hardware Back Button Navigation

## 🚀 Quick Start Guide

### For Android Users

1. **Download the APK** using the link above or scan the QR code
2. **Enable Installation from Unknown Sources**:
   - Go to Settings → Security
   - Enable "Unknown Sources" or "Install Unknown Apps"
3. **Install the APK** by tapping on the downloaded file
4. **Launch the app** and log in with provided credentials
5. **Select your language** preference (English/Hindi/Gujarati)
