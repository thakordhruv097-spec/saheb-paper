## 🎬 Camera & Movement Guide

### Shot 1: Opening Hook
- **Type:** Static → Slow Push-In
- **Speed:** 2 seconds to complete push
- **Distance:** 20cm forward movement
- **Focus:** Shallow depth of field (hands sharp, background soft blur)

### Shot 2: Problem Statement
- **Type:** Split Screen Static
- **Transition:** Swipe Left (0.4s duration, ease-out)
- **No camera movement** (keeps attention on content)

### Shot 3: Solution Reveal
- **Type:** 3D Product Rotation
- **Axis:** Y-axis rotation (90° turn revealing screen)
- **Speed:** 2 seconds for full rotation
- **Easing:** Smooth ease-in-out
- **Software Suggestion:** Blender / After Effects 3D layers

### Shot 4: Features Montage
- **Type:** Quick Cuts (no camera movement)
- **Transition:** 0.2s crossfade between features
- **Focus:** UI elements animate IN, not camera moving

### Shot 5: Builder Statement
- **Type:** 180° Orbit
- **Speed:** 4 seconds for full orbit
- **Height:** Eye-level (don't go overhead)
- **Tool:** Gimbal or slider for smooth motion

### Shot 6: Call-to-Action
- **Type:** Static (no movement)
- **Focus:** Let text animations do the work
- **Hold:** Final frame for 2 seconds

### Audio Levels
- **Music:** -18dB to -12dB (background)
- **SFX:** -6dB to -3dB (foreground)
- **Voiceover:** N/A (text-only for Instagram)

## 📱 Screen Recording Checklist

### Before Recording
- [ ] Close all unnecessary apps/windows
- [ ] Hide desktop icons (clean desktop)
- [ ] Disable notifications (Do Not Disturb mode)
- [ ] Hide browser bookmarks bar
- [ ] Set screen resolution to 1920x1080 minimum
- [ ] Clear recent search/history from UI
- [ ] Use dummy/sample data (no real customer info)

### Recording Settings
- [ ] **Frame Rate:** 60fps
- [ ] **Resolution:** 2K or higher (for cropping flexibility)
- [ ] **Recording Software:** OBS Studio / QuickTime / ShareX
- [ ] **Cursor:** Visible, medium size, smooth movement
- [ ] **Mouse Speed:** Slow down pointer for smooth motion

### What to Record (Each Module)
1. **Dashboard:** 10 seconds of smooth scrolling
2. **Raw Material:** Click into module, show live data
3. **QR Scanner:** Scan a test code, show result
4. **Reports:** Generate a chart, watch it animate
5. **User Management:** Show role assignment
6. **Label Studio:** Design preview, click print
7. **Mobile App:** Navigation on phone/tablet
