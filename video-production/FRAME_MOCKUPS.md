## 🎨 Design Assets Required

### Fonts to Download
1. **Poppins** (Google Fonts)
   - Weights: 400 (Regular), 600 (SemiBold), 700 (Bold)
   - URL: https://fonts.google.com/specimen/Poppins

2. **Inter** (Google Fonts)
   - Weights: 400 (Regular), 500 (Medium), 600 (SemiBold)
   - URL: https://fonts.google.com/specimen/Inter

3. **Fira Code** (Monospace for code)
   - Weight: 400 (Regular)
   - URL: https://fonts.google.com/specimen/Fira+Code

### Icons & Graphics
- **Lucide React Icons** (already in your project)
  - File, Package, TrendingUp, Users, Printer, etc.
- **Emoji**: Use native system emojis for quick mockups
- **Logo**: Create or use existing company logo

## ✅ Usage Checklist

### Before Creating Mockups
- [ ] Review script and storyboard first
- [ ] Confirm brand colors are correct
- [ ] Download all required fonts
- [ ] Gather logo and icon assets
- [ ] Set up project folder structure

### During Design
- [ ] Use exact colors from spec
- [ ] Match typography hierarchy
- [ ] Keep 9:16 aspect ratio locked
- [ ] Add safe zones (avoid top 200px, bottom 300px for UI elements)
- [ ] Test readability on mobile screen size

### After Design
- [ ] Export all 9 frames as PNG
- [ ] Create JPG versions for client review
- [ ] Document any design deviations
- [ ] Organize exports in "mockups" folder
- [ ] Share with team for feedback
