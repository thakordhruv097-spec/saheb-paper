## 🎨 Visual Style Guide

### Color Palette
- **Primary:** `#5E3BE8` (Purple - Your brand color)
- **Background:** `#FFFFFF` (Clean white)
- **Text:** `#1F2937` (Dark gray)
- **Accents:** `#10B981` (Success green), `#F59E0B` (Warning amber)
- **Gradient:** `linear-gradient(135deg, #5E3BE8 0%, #8B5CF6 100%)`

### Typography
- **Headlines:** Bold, Sans-serif (Poppins/Inter)
- **Body Text:** Regular, Sans-serif (Inter/Roboto)
- **Code Snippets:** Monospace (Fira Code/JetBrains Mono)

### Animation Style
- **Transitions:** Smooth, 0.3-0.5s ease curves
- **Camera Movement:** Slow, cinematic (gimbal-style)
- **UI Interactions:** Subtle micro-interactions
- **No:** Jarring cuts, spinning logos, heavy drop shadows

### Music/Audio
- **Style:** Corporate Tech / Ambient Electronic
- **Tempo:** 110-120 BPM
- **Mood:** Confident, Forward-thinking, Professional
- **Reference Tracks:**
  - "Technology" by corporate music libraries
  - Clean electronic beats with subtle synth pads
  - NO aggressive dubstep or overly energetic tracks

## 📊 Instagram Optimization

### Technical Specs
- **Resolution:** 1080x1920px (9:16)

## 🎬 Production Notes

### Required Assets
1. **Screen Recordings:**
   - Dashboard navigation (smooth mouse movements)
   - Each module in action (2-3 seconds each)
   - Mobile app responsiveness
   - QR scanning demo
   - Reports generation

2. **B-Roll Footage:**
   - Developer workspace (keyboard, multiple monitors)
   - Code being written in VS Code
   - App testing on different devices
   - Optional: Real paper mill footage (if available)

3. **Graphics:**
   - Company logo (vector/high-res)
   - Icon pack for features
   - Text overlays (animated)

### Filming Tips
1. **Lighting:** Soft, even lighting (avoid harsh shadows)
2. **Camera:** Stabilized (gimbal or tripod)
3. **Screen Recordings:** 
   - Use OBS Studio or QuickTime (Mac)
   - Record at 2K+ for flexibility in editing
   - Clean browser (no bookmarks bar, notifications off)
4. **Timing:** Practice transitions—keep them tight
