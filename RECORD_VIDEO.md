# 🎥 Video Recording Kaise Kare (Hindi)

**Date:** October 31, 2026, 10:08 PM IST

---

## Method 1: Windows Game Bar (Sabse Easy)

### Step-by-Step:

1. **Browser mein video page kholo**
   - http://localhost:8080/index.html
   
2. **Full Screen karo (Optional)**
   - F11 button dabao (cleaner video ke liye)

3. **Windows Game Bar kholo**
   - **Windows Key + G** dono saath mein dabao
   - Ek overlay dikhega screen par

4. **Record Button Dabao**
   - "Capture" widget mein **● (Circle)** button dikhega
   - Usko click karo ya **Windows + Alt + R** dabao

5. **Video Play Karo**
   - Motion graphics page mein "Play" button click karo
   - 30 seconds pura dekho (video complete hone do)

6. **Recording Stop Karo**
   - Phir se **Windows + G** dabao
   - Ya **Windows + Alt + R** (Stop recording)

7. **Video Saved!**
   - Location: `C:\Users\thako\Videos\Captures\`
   - Filename: Something like `Desktop 2026-10-31 22-10-15.mp4`

---

## Method 2: Manual (Agar Game Bar Nahi Chala)

### OBS Studio Use Karo:

1. OBS Studio download karo: https://obsproject.com/
2. Install karo
3. Sources → Window Capture → Browser select karo
4. Record button dabao
5. Video play karo
6. Stop dabao

---

## Method 3: Simple Screen Recorder

### Windows 10/11 Built-in:

1. Start → "Screen Recorder" search karo
2. Xbox Game Bar khulega
3. Record button dabao
4. Done!

---

## ❓ Problems?

**Problem: Game Bar nahi khul raha**
→ Settings → Gaming → Xbox Game Bar → ON karo

**Problem: Recording start nahi ho raha**
→ App ko "Game" consider nahi kar raha
→ OBS Studio use karo instead

**Problem: Video quality kharab hai**
→ Settings → Gaming → Captures → Video quality HIGH karo
